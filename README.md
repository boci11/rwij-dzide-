# Kalkulator

Prosty kalkulator internetowy zbudowany w HTML, CSS i JavaScript.

## Funkcje

- ➕ Dodawanie
- ➖ Odejmowanie
- ✖️ Mnożenie
- ➗ Dzielenie
- 🔄 Czyszczenie wyświetlacza
- ❌ Obsługa błędów

## Jak używać

1. Otwórz plik `calculator.html` w przeglądarce
2. Klikaj przyciski aby wykonywać operacje matematyczne
3. Kliknij `=` aby obliczyć wynik
4. Kliknij `C` aby wyczyścić wyświetlacz

## Struktura projektu

- **HTML5** - struktura
- **CSS3** - styling
